To fix or set up the board by hand, pick a piece, then tap squares to place it. Tap a square again to empty it. You play White, at the bottom.

While the board could still be a starting position, a piece placed on the top two rows is black and one on the bottom two rows is white, whichever colour you picked.

The engine's reply is filled in as soon as you enter your move, since the model predicts it exactly. If the game shows a different reply, press Undo and tap the move it played, or read a screenshot of the game (or paste one): the page works out the moves from it.

The planner models the game's engine exactly, so its prediction of each reply should match what the game plays. If a reply differs, check the board: a misplaced piece or wrong castling rights changes the engine's choice.
